Gradient Image API
Playground Docs AI OpenAPI llms.txt

URL を組み立てて、PNG が返る

サイズ・シード・色をクエリに載せるだけです。同じ URL はいつも同じ画像になります。

エンドポイント

GET /gradient が唯一の生成 API です。成功時は image/png、数値パラメータが壊れているときだけ JSON 400 です。

パラメータ型デフォルト説明
w / widthinteger800幅。16–2048 に丸めます。
h / heightinteger800高さ。16–2048 に丸めます。
seedstring0模様の種。同じ値なら同じ絵。
colorsstring#2EE59D,...HEX。カンマ / スペース / | 区切り。# はあってもなくてもよい。
warpnumber0.62流れの強さ。0–1.5。
grainnumber0.035粒子。0–0.2。
