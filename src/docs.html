ドキュメント

概要

生成は GET /gradient だけです。幅・高さ・シード・色を URL に載せると PNG が返ります。同じクエリは同じ画像になります。

試すなら Playground。

クイックスタート

ブラウザのアドレス欄、または <img> の src に次を置きます。

GET /gradient?w=800&h=800&seed=jalapeno&colors=2EE59D,4FC3F7,00ACC1

ローカル起動:

npm start
# http://localhost:8787

エンドポイント

パスGET /gradient

キャッシュ1年 / immutable

width / height も使えます。画像を返すのは /gradient だけです。

パラメータ

すべてクエリです。省略した項目はデフォルトになります。範囲外のサイズは丸めます。

名前型デフォルト範囲説明
w / width integer80016–2048 幅（px）。範囲外はクランプ。
h / height integer80016–2048 高さ（px）。範囲外はクランプ。
seed string0— 模様の種。任意の文字列。空文字は 0 扱い。
colors string#2EE59D, #4FC3F7, #00ACC1, #80DEEA2色以上 HEX。# は任意。区切りはカンマ / 空白 / |。
warp number0.620–1.5 流れの強さ。0 に近いほど塊、大きいほどリボン。
grain number0.0350–0.2 粒子感。
blur number00–32 ぼかし半径（出力 px）。0 はシャープ。

colors の解釈

各トークンは 3 桁または 6 桁 HEX だけ採用します。不正な値は捨てます。有効色が 2 つ未満ならデフォルトパレットに戻します。これはエラーではありません。 

colors=2EE59D,4FC3F7
colors=#FF6B6B|#FFD93D|#FF8C42
colors=2EE59D 4FC3F7 00ACC1

エラー

w / h / warp / grain / blur が存在するのに数値でないときだけ 400 です。 

{
  "error": "w と h は数値で指定してください"
}
HEX が壊れていても 400 にはしません。色が足りなければデフォルトに戻ります。

挙動

決定性

クエリが同じなら PNG も同じです。見た目を変えたいときは seed か colors を変えます。

キャッシュ

成功レスポンスは 1 年キャッシュします。同じ URL を何度貼っても再生成コストは CDN やブラウザ側で吸収できます。

CORS

全オリジン許可です。別サイトの <img> や fetch から使えます。
