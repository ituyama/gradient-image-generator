Gradient
Image API

URL に幅・高さ・シード・色を載せるだけで、有機的なメッシュグラデ PNG が返ります。

Playground で試す Docs を読む
GET /gradient?w=800&h=800&seed=jalapeno&colors=2EE59D,4FC3F7,00ACC1
jalapeno aurora 42 og peach
GET だけ

画像を返すのは /gradient ひとつです。キーは不要です。

同じ URL は同じ画像

クエリが同じなら PNG も同じです。見た目を変えるなら seed か colors を変えます。

そのまま貼れる

img の src、Markdown、OGP に URL を置くだけです。
